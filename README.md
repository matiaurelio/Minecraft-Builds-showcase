# Minecraft Sin Shaders Builds

**Español** · [English](README.en.md) · [Português](README.pt.md)

**Visor y animador de construcciones de Minecraft Bedrock**

Herramienta web para cargar, visualizar, animar y compartir estructuras de Minecraft Bedrock de forma rápida y visual. Ideal para constructores que quieren mostrar el proceso de construcción capa por capa o bloque a bloque, sin necesidad de shaders ni software externo.

🌐 **Demo en vivo:** [minecraftsinshadersbuilds.netlify.app](https://minecraftsinshadersbuilds.netlify.app)

---

## ¿Qué es?

Minecraft Sin Shaders Builds es una aplicación que corre completamente en el navegador. Te permite:

- Cargar archivos `.mcstructure` o `.nbt` exportados desde un bloque de estructura
- Ver la construcción en 3D con controles fluidos (rotar, zoom, diferentes ángulos)
- Reproducir la construcción **capa por capa** o **bloque a bloque**
- Aplicar texturas personalizadas (resource packs)
- Grabar un video del proceso de construcción
- Publicar tus obras en la comunidad
- Descargar la estructura lista para usar en el juego (`.mcpack`)
- Generar planos y listas de bloques

Todo ocurre en tu dispositivo. La estructura solo se sube si vos decidís publicarla.

---

## Características principales

| Función                    | Descripción                                      |
|---------------------------|--------------------------------------------------|
| **Visor 3D**              | Rotación libre, zoom y vistas isométrica / superior / frontal / lateral |
| **Animación**             | Construcción por capas o por bloques individuales |
| **Texturas**              | Cargá resource packs o usá las predeterminadas   |
| **Grabación de video**    | Exportá el proceso de construcción en HD         |
| **Planos**                | Vista en planta + exportación de lista de bloques |
| **Cámara libre**          | Navegá por dentro de la construcción (WASD)      |
| **Comunidad**             | Publicá y explorá obras de otros constructores   |
| **Multi-parte**           | Combiná hasta 4 archivos para construcciones grandes |

---

## Cómo se usa (resumen)

1. **Cargá** tu archivo `.mcstructure` o `.nbt` (o arrastralo al visor)
2. **Aplicá texturas** si querés (opcional)
3. **Reproducí** la animación de construcción
4. **Ajustá** la cámara y la vista
5. **Grabá** un video o **publicá** la obra
6. **Descargá** el `.mcpack` para usarlo en Minecraft

## Comparación con otras herramientas 3D

| Herramienta                        | Enfoque principal              | Animación de construcción | Grabación de video | Texturas personalizadas | Comunidad |
|------------------------------------|--------------------------------|---------------------------|--------------------|--------------------------|---------|
| **Minecraft Sin Shaders Builds**   | Presentación y animación       | Excelente                 | Sí                 | Sí                       | Sí      |
| Shulkr Viewer                      | Inspección 3D                  | Buena                     | No                 | Limitada                 | Sí      |
| Bloxelizer                         | Visualización + conversión     | Buena                     | No                 | Limitada                 | Sí      |
| Minecraftmaps Structure Viewer     | Estructuras vanilla + propias  | Básica                    | No                 | No                       | No      |
| Cubical.xyz                        | Editor online completo         | No prioritario            | No                 | Limitada                 | No      |

**Diferencial clave:**  
Mientras la mayoría de herramientas se centran en inspeccionar o convertir esquemas, Minecraft Sin Shaders Builds está pensada para **mostrar el proceso de construcción** de forma atractiva (ideal para creadores de contenido y presentaciones).
