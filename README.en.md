# Minecraft Sin Shaders Builds

[Español](README.md) · **English** · [Português](README.pt.md)

**3D Viewer and Animator for Minecraft Bedrock Builds**

A web tool to load, visualize, animate, and share Minecraft Bedrock structures quickly and visually. Perfect for builders who want to showcase the construction process layer by layer or block by block, without needing shaders or external software.

🌐 **Live demo:** [minecraftsinshadersbuilds.netlify.app](https://minecraftsinshadersbuilds.netlify.app)

---

## What is it?

Minecraft Sin Shaders Builds is a fully browser-based application that lets you:

- Load `.mcstructure` or `.nbt` files exported from a structure block
- View the build in 3D with smooth controls (rotate, zoom, different angles)
- Play the construction **layer by layer** or **block by block**
- Apply custom textures (resource packs)
- Record a video of the building process
- Publish your builds to the community
- Download the structure ready to use in-game (`.mcpack`)
- Generate plans and block lists

Everything runs on your device. The structure is only uploaded if you decide to publish it.

## Main Features

| Feature                   | Description                                              |
|---------------------------|----------------------------------------------------------|
| **3D Viewer**             | Free rotation, zoom, and isometric / top / front / side views |
| **Animation**             | Build layer by layer or block by block                   |
| **Textures**              | Load resource packs or use the defaults                  |
| **Video Recording**       | Export the construction process in HD                    |
| **Plans**                 | Top-down view + block list export                        |
| **Free Camera**           | Navigate inside the build (WASD)                         |
| **Community**             | Publish and explore other builders' works                |
| **Multi-part**            | Combine up to 4 files for large builds                   |

---

## How to use (summary)

1. **Load** your `.mcstructure` or `.nbt` file (or drag it into the viewer)
2. **Apply textures** if you want (optional)
3. **Play** the construction animation
4. **Adjust** the camera and view
5. **Record** a video or **publish** the build
6. **Download** the `.mcpack` to use it in Minecraft

## Comparison with other 3D tools

| Tool                               | Main Focus                     | Construction Animation | Video Recording | Custom Textures | Community |
|------------------------------------|--------------------------------|------------------------|-----------------|------------------|-----------|
| **Minecraft Sin Shaders Builds**   | Presentation & animation       | Excellent              | Yes             | Yes              | Yes       |
| Shulkr Viewer                      | 3D inspection                  | Good                   | No              | Limited          | Yes       |
| Bloxelizer                         | Viewing + conversion           | Good                   | No              | Limited          | Yes       |
| Minecraftmaps Structure Viewer     | Vanilla + custom structures    | Basic                  | No              | No               | No        |
| Cubical.xyz                        | Full online editor             | Not the priority       | No              | Limited          | No        |

**Key difference:**  
While most tools focus on inspecting or converting schematics, Minecraft Sin Shaders Builds is designed to **showcase the building process** in an attractive way (ideal for content creators and presentations).
